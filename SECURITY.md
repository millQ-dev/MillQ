# Security policy

## Supported versions

Security support details will be defined once MillQ releases are published.

| Version | Supported |
| ------- | --------- |
| Unreleased | Not yet applicable |

## Reporting a vulnerability

If you discover a security issue in MillQ, please report it privately.

Do not open a public GitHub issue or a public Origin pull request for security vulnerabilities.

Until a dedicated security contact is published, report potential issues privately to the Cursor Origin repository maintainers. GitHub `millQ-dev` is a backup mirror only and must not be used as the live intake channel.

Please include:

- a description of the issue
- steps to reproduce, if possible
- potential impact
- any suggested remediation

We will acknowledge reports and provide next steps after review.

This policy is a placeholder and will be updated as the project matures.
