# Security policy

## Supported versions

Security support details will be defined once MillQ releases are published.

| Version | Supported |
| ------- | --------- |
| Unreleased | Not yet applicable |

## Reporting a vulnerability

If you discover a security issue in MillQ, please report it privately.

Do not open a public GitHub issue for security vulnerabilities.

Until a dedicated security contact is published, report potential issues through the private repository maintainers for the `millQ-dev` organization.

Please include:

- a description of the issue
- steps to reproduce, if possible
- potential impact
- any suggested remediation

We will acknowledge reports and provide next steps after review.

This policy is a placeholder and will be updated as the project matures.
